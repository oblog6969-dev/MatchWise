# 💬 Release v2.7.0 — Interactive Tooltips & Vector Print Fidelity

> [!summary] Release Details
> **Version:** `v2.7.0`  
> **Release Date:** August 2026  
> **Milestone:** [[M11 - Interactive Popovers & Print Fidelity]]  
> **Status:** ✅ Production Ready

### ✨ Added
- **`ChartTooltipManager`**: High-performance tooltip controller supporting both desktop hover events and mobile/tablet touch taps.
- **`CHART_EXPLANATION_DICTIONARY`**: Rich clinical descriptions across all 10+ psychometric frameworks in both English and Arabic.
- **Dynamic Mobile Backdrop**: Dismissal backdrop for touch screens (`.mw-chart-touch-backdrop`).
- **Strict Print Stylesheet**: Suppressed all interactive popovers, backdrops, and pulsing rings during print previews and paper exports to keep vector graphics 100% clean.
