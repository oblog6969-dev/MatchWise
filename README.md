# MatchWise Lite v1.2

MatchWise Lite is a production-quality, offline relationship compatibility assessment tool. It is designed to run entirely inside the browser without requiring any backend, database, login, API, or internet connection.

## Tech Stack
- HTML5
- CSS3 (Premium dark/light support, glassmorphism, responsive, LTR & RTL Arabic layouts)
- Vanilla JavaScript (ES6)

## Structure
- `index.html`: Base entry point with semantic modern SPA tabs.
- `style.css`: Clean, elegant Apple-inspired UI design system.
- `script.js`: App controller coordinating the state, adaptive logic, and responsive custom SVG charts.
- `questions.json`: Structured, bilingual, adaptive question database (73 questions) with diverse item types.
- `traits.js`: Multi-trait psychometric parsing engine.
- `compatibility.js`: Deep multivariable relationship compatibility scorer and advice advisor.
- `utils.js`: Localization dictionary, storage wrappers, theme managers, and lightweight base64/position-xor profile encryptors.

## Getting Started
Open `index.html` directly in any modern desktop or mobile browser. Everything works entirely offline instantly.
